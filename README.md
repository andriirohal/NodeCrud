# 🌱 Understory

A full-stack microservices e-commerce platform for selling plants, built with TypeScript, Go, Express, Vite, and PostgreSQL.

---

## ✨ Features

* User authentication with JWT
* Plant catalog with filtering and sorting
* Shopping cart and wishlist
* Checkout and order management
* Multilingual support (EN, DE, PL, UA)
* Responsive design

---

## 🛠️ Tech Stack

* TypeScript
* Go
* Express
* Gin
* Vite
* SCSS
* PostgreSQL
